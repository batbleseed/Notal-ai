⚙️ Technical Details

Architecture

  • Hosting: GitHub Pages (Serverless)
  • Runtime: 100% Client-Side (Browser)
  • Data Storage: localStorage (Privacy-First)
  • API Integration: Native API calls to each provider
  • Framework: Vanilla JavaScript + Font Awesome

Features

  • Chat: Real-time conversation with AI models
  • Image Generation: DALL-E, Stable Diffusion, Imagen 3
  • Vision: Image analysis with GPT-4o, Claude, Gemini
  • Web Browsing: Fetch and parse web pages via CORS proxies
  • Code Preview: Live HTML preview in iframe
  • Thinking Animation: ChatGPT-style with stage indicators
  • File Upload: Images, PDFs, text, and code files
  • Dark/Light Theme: Toggle between themes
  • Chat History: Save and load conversations

📸 Quick Start

  1. Open https://batbleseed.github.io/Notal-ai/studio.html
  2. Add API Key in Settings (⚙️ icon)
  3. Select Model from the dropdown
  4. Start Chatting! Try commands like:
    • Generate an image of a futuristic city
    • Browse https://example.com
    • Write a Python function to sort a list
    • Upload an image and ask "What's in this image?"
